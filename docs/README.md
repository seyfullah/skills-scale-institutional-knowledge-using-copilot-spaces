# OctoAcme Project Management Docs

This repository contains the core project management guidance used by OctoAcme. The goal of these docs is to standardize how the team initiates, plans, executes, communicates, releases, and continuously improves projects.

## Project management process summary

OctoAcme uses a lightweight, cross-functional project lifecycle that starts with initiation and planning, then moves into execution, risk and communication management, delivery, release, and retrospective-driven improvement. The process emphasizes clear ownership, stakeholder alignment, iterative delivery, measurable outcomes, risk management, and regular communication across the team.

## How to use these docs

Use the overview for a high-level understanding of the OctoAcme process, then refer to the more specific documents based on the phase of work: initiation, planning, execution, risk management, release, and retrospectives.

These docs help the team stay aligned on roles, responsibilities, delivery rhythm, decision-making, and continuous improvement while keeping project work visible and measurable.
